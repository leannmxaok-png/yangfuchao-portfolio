未连接仓库

先接上你的仓库

需要一个 GitHub Token（只给这一个仓库的读写权限）。生成一次，存在这台电脑的浏览器里，以后不用再填。

生成路径：GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
Repository access 只勾 yangfuchao-portfolio； Permissions 里 Contents 设为 Read and write。

只存本机浏览器 localStorage，不会发到任何第三方。

选一个项目编辑。
改完点右上角「保存并发布」，约 1 分钟上线。
